About the Project

Game3D FPS is a passion project demonstrating advanced game development skills using Unity 3D. The game features a complete FPS experience with AI-driven enemies, multiple weapon systems, and immersive 3D environments. Built with modern game development practices and optimized for performance.

This project showcases expertise in Unity development, C# programming, 3D modeling integration, AI behavior programming, and user interface design. The game includes custom animations, particle effects, and sound systems for a complete gaming experience.
